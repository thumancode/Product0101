# প্রোডাক্ট মোশন ভিডিও মেকার (GitHub Actions)

আপনি দেবেন: **অডিও + SRT + প্রোডাক্ট ছবি (+ ইচ্ছে হলে ব্যাকগ্রাউন্ড মিউজিক)**।
GitHub নিজে ভিডিও (MP4, 1080x1920, Facebook Reels / পেইজ ভিডিওর মাপ) বানিয়ে দেবে।
সব গ্রাফিক্স ভেক্টর, কোনো ইমোজি নেই। হুক, whoosh, pop, chime সাউন্ড কোড দিয়ে নিজে তৈরি হয়।

## একবারের সেটআপ (মোবাইল ব্রাউজারেই হবে)

1. GitHub-এ একটা নতুন repository খুলুন। Public রাখলে Actions বিনা খরচে চলে।
   Private হলে মাসে ২০০০ মিনিট ফ্রি, এক ভিডিও আনুমানিক ১৫-২৫ মিনিট নেয়।
2. **Add file > Upload files** দিয়ে এই ফাইলগুলো আপলোড করে Commit করুন:
   - `make_video.py`
   - `config.json`
   - `Product01.mp3` (আপনার অডিও)
   - `subtitles.srt` (আপনার SRT। `.txt` হলেও চলবে)
   - `product.webp` (প্রোডাক্ট ছবি। `.png` বা `.jpg` হলেও চলবে)
3. **Add file > Create new file** চাপুন। নামের ঘরে হুবহু লিখুন:
   `.github/workflows/render-video.yml`
   (স্ল্যাশ `/` লিখলেই GitHub নিজে ফোল্ডার বানিয়ে নেয়।)
   নিচের বড় ঘরে `render-video.yml` ফাইলের পুরো লেখা পেস্ট করে **Commit changes** দিন।

## ভিডিও বানানো

1. repository-র **Actions** ট্যাবে যান, বাম পাশে **Render video** বাছুন।
   (মোবাইলে বাটন না দেখলে ব্রাউজারের **Desktop site** অন করুন।)
2. **Run workflow** চাপুন:
   - folder: ফাইলগুলো মূল ফোল্ডারে থাকলে `.` (ডট) রেখে দিন
   - quality: `full` (শেষ ভিডিও) বা `preview` (দ্রুত ছোট পরীক্ষা)
3. সবুজ টিক আসা পর্যন্ত অপেক্ষা করুন।
4. ভিডিও নামাতে: repository-র মূল পাতায় ডান পাশে **Releases** > সর্বশেষ `Video #…` > নিচের `video-….mp4` চাপুন।
   বিকল্প: ওই রানের পাতার নিচে **Artifacts** থেকে নামান (zip আকারে আসে)।

## ব্যাকগ্রাউন্ড মিউজিক

নিজের মিউজিক ফাইল `bgm.mp3` নামে আপলোড করুন। ভিডিওতে নিজে থেকে মিশবে এবং কথা বলার সময় আওয়াজ কমে যাবে।
আওয়াজ কম বা বেশি করতে `config.json`-এ `"bgmVolume": 0.16` বদলান (০.০৫ = খুব নিচু, ০.৩ = জোরে)।

## config.json-এ যা বদলানো যায়

| ঘর | মানে |
|---|---|
| `brand` | নিচের ব্র্যান্ড নাম, যেমন `Elence Fragrance` |
| `website` | ওয়েবসাইট লিংক, যেমন `elencefragrance.com`। ফাঁকা রাখলে কিছু দেখাবে না |
| `presenter` | শুরুর "Rizwan Talks" লেখা |
| `productName`, `productSubtitle` | প্রোডাক্টের নাম ও উপশিরোনাম |
| `sync` | `auto` = অডিওর বিরতি দেখে ক্যাপশন মেলানো (ডিফল্ট)। আপনার SRT-এর সময় নিখুঁত হলে `srt` |
| `scenes` | সিনের তালিকা। নোটস, ট্রেইটস, অকেশন ইত্যাদির লেখা ও রং এখানে |

নতুন প্রোডাক্টের জন্য সবচেয়ে সহজ উপায়: অডিও, SRT, ছবি আমাকে দিন, আমি নতুন `config.json` বানিয়ে দেব।

## একাধিক প্রোডাক্ট

নতুন ফোল্ডার বানাতে **Create new file** চেপে নামে লিখুন `product02/config.json`, ভেতরে সেই প্রোডাক্টের config পেস্ট করুন।
তারপর ওই ফোল্ডারে ঢুকে **Add file > Upload files** দিয়ে অডিও, SRT, ছবি দিন।
রান করার সময় folder ঘরে `product02` লিখুন।

## সমস্যা হলে

- **লাল ক্রস এলে**: ওই রানে ক্লিক করে **Render video** ধাপ খুলে শেষের কয়েক লাইন আমাকে পাঠান।
- **"ফোল্ডারে অডিও, সাবটাইটেল আর ছবি তিনটাই লাগবে"**: তিনটা ফাইলই ঠিক ফোল্ডারে আছে কিনা দেখুন।
- **ক্যাপশন অডিওর সাথে একটু আগে-পরে লাগলে**: SRT-এ নিখুঁত সময় থাকলে `"sync": "srt"` দিন। না থাকলে আমাকে জানান।
- ছবির ব্যাকগ্রাউন্ড সাদা বা হালকা ধূসর হলে সবচেয়ে ভালো মিশবে।
